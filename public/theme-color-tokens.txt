KEY DESIGN DECISIONS
- Brand red (--primary) stays identical across all themes for consistency
- Light mode flips bg/fg, lightens surfaces, and slightly darkens accent/chart colors for contrast on white
- System mode = prefers-color-scheme media query, automatically picking Light or Dark
- Glass effect in light mode uses hsl(0 0% 100% / 0.6) instead of the current dark glass
